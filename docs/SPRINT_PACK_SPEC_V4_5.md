# Sprint Pack Specification V4.5

**Date:** 2026-02-27
**Definition of Done:** A set of deliverables coherent enough to execute 7 days of marketing operations without extra human thinking.

## B1. Lead/CRM Sprint Pack
- **ICP + Persona:** Minimum viable target audience definition.
- **Offer + 3 Angles:** The core product offer framed in 3 different psychological hooks.
- **Funnel 3-Step Plan:** Top, Middle, Bottom funnel mapping.
- **CRM Pipeline Stages:** Recommended stage names for ERPNext/FluentCRM.
- **2 Nurturing Sequences:** Exact copy (Email or Zalo) for 2 automated touchpoints.
- **Sales Follow-up Checklist:** 7-day daily operations checklist for the sales rep.

## B2. Content Sprint Pack
- **Content Calendar (7/14/30 days):** Thematic posting schedule.
- **10 Hooks + 10 CTAs:** Reusable library for social media.
- **10 Post Drafts:** Multi-channel short-form copy.
- **3 Short Video Scripts:** TikTok/Reels style vertical video scripts (Hook, Body, CTA).
- **Key Visual Brief:** Design prompts for the graphic designer.

## B3. Weekly Growth Report Pack
- **KPI Summary Template:** Required inputs and basic computations (CPA, ROAS).
- **3 Decisions for Next Week:** AI-recommended pivot or scale decisions based on the KPIs.
- **5 Prioritized Tasks:** Impact vs. Effort ranked tasks for the upcoming week.
