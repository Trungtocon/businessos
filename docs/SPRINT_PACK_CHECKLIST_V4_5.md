# Sprint Pack UI Checklist V4.5

**Date:** 2026-02-27

This checklist maps the desired Sprint Pack specifications to the required UI features.

## General UI Requirements
- [ ] **Onboarding Form (Minimal Input Wizard):** Fields for Industry, Offer, Target Customer, Budget Range, Tone.
- [ ] **Unified Dashboard:** A central view to present the multi-part deliverables cleanly (not raw JSON).
- [ ] **Action Approval Review:** A visual UI to preview what data is being synced to the CRM before clicking 'Approve'.
- [ ] **Export Options:** Button to 'Download as Markdown' or 'Copy as JSON'.

## Lead/CRM Pack UI
- [ ] **ICP & Persona Display:** Cleanly formatted text blocks.
- [ ] **Funnel Plan Visualization:** Simple 3-step timeline or cards.
- [ ] **Sequence Editor:** Textareas allowing the user to tweak the AI-generated Email/Zalo copy before approval.

## Content Pack UI
- [ ] **Content Calendar:** A simple table or Kanban-style view (7/14/30 days).
- [ ] **Hook/CTA Library:** Accordion list or chips for easy copy-pasting.
- [ ] **Post Drafts & Video Scripts:** Card list view.

## Report Pack UI
- [ ] **KPI Inputs:** Simple numerical input fields for the user to provide baseline metrics before the AI generates the report.
- [ ] **Task Prioritization:** A drag-and-drop or simply ordered list of the top 5 next actions.
