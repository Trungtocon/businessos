# Product TTV Blockers V4.5

**Date:** 2026-02-27
**Status:** 🚨 NO-GO

## 1. Missing Entry Points (P0)
There is no clear button, card, or navigation link on `/virtual` to initiate a "Lead Sprint Pack", "Content Sprint Pack", or "Growth Report Sprint Pack". A user currently lands on the dashboard and must figure out how to manually stitch together generic Copilot prompts.

## 2. Missing Onboarding Context (P0)
The AI Copilot relies on a text-heavy `Project Brief` and `Website Context` input. There is no minimal wizard (Industry, Offer, Audience, Budget) to quickly cold-start a Sprint Pack for a new SME user.

## 3. Disconnected Deliverable UX (P0)
The current AI UI shows one JSON schema result at a time. A "Sprint Pack" requires a dashboard view of a multi-part output (e.g., ICP + Funnel + Sequence). The current `JsonResultViewer` is too raw for a non-technical SME user looking for a finished marketing deliverable.
